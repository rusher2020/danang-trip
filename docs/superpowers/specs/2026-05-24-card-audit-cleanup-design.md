# 후보카드 감사 정리 설계 (Card Audit Cleanup)

> 작성 2026-05-24. **이 세션은 설계, 구현은 별도 세션**(executing-plans). 레퍼런스(first6/family-trip-2605)를 기준선으로 우리 풀의 결함을 전수 감사해 도출.

## 배경·문제

후보카드는 옛 아카이브 `github.com/first6/family-trip-2605/4-candidates/`에서 임포트됨. 이전 세션에서 정합성(날짜·나이·숙소)은 정리 완료(커밋 `b04eb7f`). 이번엔 **구조적 결함**을 정리한다.

데이터 감사(2026-05-24) 결과 실제 결함:
- 동일 장소가 풍부본 + 빈약 스텁으로 **중복**
- 일부 카드가 잘못된 카테고리(자연·해변)에 **오분류**
- 9.1 인천공항 좌표가 인천(37.46,126.44)이라 다낭 지도 **이탈 핀**
- 1.1·1.3·1.4 이미지가 옛 레포(first6) **외부 의존**

현재 라이브 카드 107장(정적 103 + 하얏트 4). 정합성 잔여 마커 0(검증됨).

## 목표

중복·오분류·이탈핀·외부이미지 의존을 제거/정리해 풀을 깔끔하게. **하드삭제 금지** — 제거 카드는 `archive/`에 보존(+git 복구 가능).
