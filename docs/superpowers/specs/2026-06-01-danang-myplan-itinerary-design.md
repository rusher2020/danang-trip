## 1. 배경 및 목표

항공·숙박만 확정된 상태에서, 일자별 일정이 비어 있는 **"📝 내 일정"(myPlan)** 을 다낭 전문가 관점으로 완성한다.

**스코프 (엄격)**
- **"내 플랜"(myPlan) 한 곳만** 채운다.
- **프리셋 5개안(A 휴식 / B 호이안 / C 문화 / D 카페 / E 균형)은 절대 건드리지 않는다.**

## 9. 반영 방법 (실행 세션에서)

myPlan은 `danang-myplan`(localStorage + URL해시) 객체. **"내 일정"에 본 일정을 기본 시드로 심는다.**

- 본 일정을 §4 데이터 모델(`myPlan.days["7/24"] = [item...]`)로 직렬화.
  - [카드] 항목 → `{source:"card", time, cardId, note?}` (cardId는 이름으로 `CANDIDATE_DATA`에서 매핑)
  - [커스텀] 항목 → `{source:"preset", time, icon, title, tag, desc, place?}`
- 시드 주입 방식 결정 필요(실행 세션 1차 작업): (a) index.html에 `DEFAULT_MYPLAN` 상수로 두고 "내 일정" 최초 진입 시 비어있으면 시드, 또는 (b) 공유 URL 해시 생성해 전달. **권장: (a) 기본 시드** — "github 스케줄러에 반영" 요구에 부합.
- `ITINERARIES`(A~E) **불변** 보장. `renderTimeline`/`renderMap` 재사용.
- §4의 아이 나이·교통 메모 정정 동반.
- 검증: 헤드리스 playwright로 "내 일정" 탭 6일 렌더·지도 핀·프리셋 정상·JS 에러 0 (`docs/RESUMING.md` 도구).
